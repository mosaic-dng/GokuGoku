# GokuGoku v1.3.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish GokuGoku v1.3.0 with synchronized README screenshots, documentation, version metadata, and a verified Windows x64 portable release.

**Architecture:** Keep the application and schema unchanged beyond the already implemented snooze feature. Add release-contract tests first, generate screenshots from the real Electron app, build and verify the portable package locally, then fast-forward `main` and trigger the existing tag-based GitHub Release workflow.

**Tech Stack:** Electron 43, Node.js built-in test runner, PowerShell, Git, GitHub Actions
